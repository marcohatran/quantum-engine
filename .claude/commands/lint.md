# Lint

Run static analysis and code formatting checks with clang-tidy and clang-format.

## Usage

```
/lint [--fix] [path]
```

- `--fix`: auto-apply formatting corrections (clang-format only)
- `path`: limit to a specific file or directory (default: all changed files vs `main`)

## Steps

1. Identify files to check (git diff vs `main`, or the specified path).
2. Run clang-format check:
   ```bash
   clang-format --dry-run --Werror <files>
   # With --fix:
   clang-format -i <files>
   ```
3. Run clang-tidy (requires `compile_commands.json` from a CMake configure step):
   ```bash
   clang-tidy -p build-debug <files>
   ```
4. Report all violations with file:line references.

## Notes

- `compile_commands.json` is generated by CMake when `-DCMAKE_EXPORT_COMPILE_COMMANDS=ON` is set. Add this flag to the configure step if it's missing.
- clang-tidy checks are configured via `.clang-tidy` at the repo root (create one if absent).
- clang-format style is configured via `.clang-format` at the repo root.
